# scava

Este repositório contém exemplos e utilidades para estudos de códigos. Além do script **complex_pine_strategy.pine**, que demonstra uma estratégia avançada de trading combinando diversos indicadores, agora também inclui **elite_trader_strategy.pine**. Este último é um exemplo robusto com múltiplas métricas (EMAs, RSI, MACD, OBV, VWAP, suporte/resistência, filtros de volume e dias da semana) e lógica de gestão de risco.
